---
name: pdf-text-to-md
description: 将带文本层的电子版 PDF 全文直提为 Markdown（脚本提取、非 OCR，内容零丢失）：以 `<!-- 第 N 页 -->` 注释分页、章节标题从 h2 起逐级提升、带框线表格还原为 Markdown 表格（含合并单元格、折行单元格处理）；混合型 PDF 的零文本页/乱码页自动回退为图像识别。适用：原生导出、可选中复制文字的 PDF。进入方式：通常由 pdf-to-md skill 检测（退出码 0）后调用；用户已知 PDF 带文本层时也可直接指定本 skill。
---

## Workflow：文本层直提路线（有文本层的电子版 PDF）

占位符约定：

- 【输入文件】：用户指定的 PDF 文件完整路径
- 【输入文件所在目录】：该 PDF 所在目录
- 【输入文件名】：PDF 文件名去掉扩展名（如 `report.pdf` → `report`）
- 【清洗后输入文件名】/【清洗后图名】：将【输入文件名】/【图名】中的空格及其他非法字符（`\ / : * ? " < > |` 及控制字符）替换为下划线 `_` 得到（如 `SFT 0028-2018 智慧监狱 技术规范` → `SFT_0028-2018_智慧监狱_技术规范`）
- 【skill目录】：本 skill 所在目录（`<skill目录>` 即本文件所在目录）
- 【图片目录】：【输入文件所在目录】/tmp_【清洗后输入文件名】/（步骤3 回退导出 PNG 与 pdf-img-to-md 图片路线使用；每个 PDF 独占一份，同一目录下多份 PDF 并行处理互不干扰）

### 步骤1：安装依赖

1. 依赖清单见本 skill 目录下的 `requirements.txt`（pymupdf），安装命令：

   ```bash
   pip install -r <skill目录>/requirements.txt
   ```

   国内网络下 pip 默认源可能长时间无响应，直接改用镜像：

   ```bash
   pip install -r <skill目录>/requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
   ```

2. 脚本启动时会自查依赖，缺依赖时打印安装提示并退出；按提示补装后重跑即可。

### 步骤2：文本流提取 + 表格还原

```bash
python -X utf8 <skill目录>/scripts/extract_pdf_to_md.py "【输入文件】" [-o "【输入文件所在目录】/【输入文件名】.md"]
```

- 默认输出：与 PDF 同目录同名 `.md`。
- 脚本自动完成：逐页 `<!-- 第 N 页 -->` 注释分页、页脚（页码/打印日期）识别与移除、页码映射验证、章节标题提升（`##`/`###`，从 h2 起逐级安排）、带框线表格还原为 Markdown 表格（伪表格过滤 + 覆盖校验兜底 + 折行单元格合并）。
- 脚本结束会打印：输出路径、还原表格数、校验回退页、乱码回退页、页脚命中数、章节标题数。
- **乱码守卫**：脚本直提前先逐页检测文本层乱码（替换符/私用区字符/(cid:) 占位符、Latin-1 区字符占比过高、单一字符高度重复、经典乱码串"锟斤拷"）。若乱码页占有效内容页 ≥ 5%，脚本**以退出码 3 直接中止且不生成输出文件**——此时放弃文本层提取，加载 pdf-img-to-md skill 走图片 OCR 路线；个别乱码页（<5%）不入正文，仅在对应 `<!-- 第 N 页 -->` 注释后留下 `<!-- 本页文本层乱码… -->` 注释，按步骤3 用图像识别补齐后替换该注释。

### 步骤3：混合型 PDF 的零文本页/乱码页回退（仅当检测出零文本页或乱码页时；检测上下文由 pdf-to-md 带入；直接调用时，乱码页清单取步骤2 脚本汇总输出，零文本页清单可扫描输出 md 中无内容的 `<!-- 第 N 页 -->` 段，或先运行入口 skill 的 `check_textlayer.py` 获取两份清单）

1. 仅导出零文本页/乱码页为 PNG（以零文本页为第 3、5 页为例）：

   ```bash
   python -X utf8 <skill目录>/scripts/pdf_to_png.py "【输入文件】" --start-page 3 --end-page 3
   ```

   多页时按连续区间逐段调用；PNG 输出到【图片目录】，命名规则同 pdf-img-to-md 的步骤2.2（【清洗后输入文件名】_NN.png，页码按总页数自动补零）。

2. 对每张回退页 PNG，用多模态子agent识别（主 agent 派发，每个子agent读取一张图片），输出临时 md 后并入主 md 对应 `<!-- 第 N 页 -->` 注释之后（若其后留有 `<!-- 本页文本层乱码… -->` 注释，用识别出的内容替换该注释）。识别要求：

   - 识别图片内容，提取文本、表格、公式等信息，按原文及原有格式输出到 md；表格尽量保持原有结构与格式。
   - 忽略图片中的水印、页眉页脚、页码等非内容信息。
   - **含图标记**（与 pdf-img-to-md 步骤3.3 的含图标记约定完全一致，便于后续衔接其步骤4 提图）：本页含可提取的插图（示意图、架构图、拓扑图、照片、统计图表等，区别于装饰性水印）时，在临时 md 的有图位置追加一行：`<!-- 本页含图: 图名（若图注/图中已有明确名称则用其名称；无名称用一句话描述内容） -->`；仅需一句话标记，不要输出定位坐标、不要裁剪。
   - **对开页（双页并排）处理**：先识别装订线/中缝位置作为左右分页基准线，拆分左页、右页分别识别（先左后右、从上到下）；左右两页表格跨页关联时合并处理，保证表格完整。
   - **引号兼容**：子agent写入的含图标记可能用 ASCII 直引号（U+0022）或中文弯引号（U+201C/U+201D），替换为图片引用前先 grep 原文按实际字符精确匹配，两种引号模式都要兼容。

3. 若回退页含可提取插图、需完整执行「多模态定位 → 程序裁剪 → 多模态校验 → 更新md引用」流程，加载 `pdf-img-to-md` skill 并执行其步骤4 提图流程（其【图片目录】约定与本 skill 一致，可直接复用已导出的回退页 PNG）。

### 步骤4：验证与交付

1. 用 `present_files` 交付 .md 文件。
2. 抽查 2–3 个关键页的渲染效果（表格页、条款首页）确认无乱序、无伪表格残留。
3. 在回复中报告：页数、还原表格数、页码映射偏移、回退页（零文本页/乱码页，如有；乱码回退页须已按步骤3 用图像识别补齐）。

#### 文本层路线要点（复杂版式定制实战记录）

extract_pdf_to_md.py 覆盖常见版式；以下要点实测于 74 页 / 8.7 万字电子保单（脚本一次跑通、零 OCR 误差），当文档版式超出脚本能力、需要定制处理时参考：

1. **三栏切分**：合同/条款类正文常为「编号栏 / 名称栏 / 正文栏」三栏版式。用 `get_text('rawdict')` 取**字符级**坐标，按 x 分栏（本例编号 x<100、名称 100≤x<199、正文 x≥199）。**正文栏左边界取实测众数减 2**（本例实测 201.6 → 取 199），否则正文会被误判为名称，导致标题行被正文灌满。
2. **名称可越界**：名称栏最右可达 ~236（如"合同效力的中止及恢复"），不能用固定 200 一刀切。判定规则改为：span 起点 x≥正文左界 → 正文；否则为编号/名称；仅当"跨栏合并 span"（x1>250，名称与定义首行被合成一个 span，本例仅 1 处）才在名称与正文之间的**空格处**切开。
3. **上下标自成一行**：`10^9/L` 这类上标在 PyMuPDF 中是**独立 line**，且 y0 可能比主行更小，按 (y,x) 排序会把正文顺序打乱（实测出现"新生儿 Hb＜100g9/L"，正确为"…g/L），PLTS＜100×109/L"）。解决：按 **span 行底 y1 排序**，并按"纵向重叠"归并同一视觉行（`sp.y0 <= row.y1-1 且 sp.y1 >= row.y0+1`），行内再按 x 排序。
4. **标题跨多行 + 正文同行**：小节名称可能换行 2~8 行且与正文首行同一 y。做法：标题名持续累积"只要还没遇到下一个编号行"，**标题与其下段落延迟输出**（用 pending head + items 缓冲，遇到下一个编号行时整块落盘），否则标题名会被截断或正文被吞。
5. **段落拼接规则**：`上一行满行（x1≥右边界-20） 且 行距≤15（正文行距 13~14，段间距 16~17） 且 下一行不匹配段首模式 且 上一行不以"："结尾`。段首模式：`（n）`、`①`、`a)`、`^\d+[、.](?!\d)`（注意加 `(?!\d)`，否则 "13.1)" 会被误判）、`注：`、`一、`、`（一）`。
6. **跨页断裂**：正文段落直接跨页续接（不做任何页间处理即可），但**表格跨页必须合并**（现金价值表、利益演示表、健康告知表）——脚本不处理跨页表格，需在合并/校对阶段人工或脚本合并。
7. **加粗 = 黑体**：源文档的重点内容用"黑体"字体（注意字体名常为 mojibake，需 `s.encode('latin-1').decode('utf-8')` 还原后判断），转换时映射为 `**…**`；**纯标点的独立加粗段**（如 `**。**`、`**”**`）要并入相邻段，否则满篇噪声。
8. **表单页 n/o 是复选框**：`Wingdings` 字体的 `n`=■（已勾选）、`o`=□（未勾选），页内说明通常写作"表格中使用"■"代表投保人已经勾选的信息"。按列位置还原成"■是 □否"这类可读文本。
9. **Coverage 校验（替代逐页人工核对，必做）**：用 `difflib.SequenceMatcher(None, 源页文本, 全md文本).get_matching_blocks()` 计算**每页匹配率**，逐页输出 <98.5% 的页并打印**未匹配片段**。合法的低分页只有"有意重排"的页（目录页、表单页、利益演示表页）；正文页低于 99% 一定有丢失，按未匹配片段定位规则缺陷。另外用"数量声明自检"做完整性证明：条款中"本合同所定义的X疾病共有N种"与 `X.` 编号条目数比对（本例 55/30/135/20/33 全部吻合）。
10. **任务量参考**：74 页电子版保单，文本层路线约 20~30 次工具调用、脚本一次成型；同文档走图片 OCR 路线需 15 批 × 5 子agent，且受 429 配额限制（见 pdf-img-to-md skill 实践经验"429 兜底"条）。

#### 参数定制

标题识别已通用化，处理任何带文本层 PDF 无需改代码：脚本先按**字号/加粗启发式**（预扫描全文，以正文众数字号为基准——字号显著更大的短行 → `##`，整行加粗的短行 → `###`），再按**通用中文文档模式**（第X章/节/篇、附录/附件、附表N：、引言/前言/概述/总则、目录、`1、xx` 等编号小标题）兜底。版式特殊识别不足时，用 `--title-pats` 追加标题正则兜底（可多次传入；显式模式优先且不受防误判约束，宽松正则的误判由调用方负责）：

```bash
python -X utf8 <skill目录>/scripts/extract_pdf_to_md.py "【输入文件】" --title-pats '^保障计划一览表$' --title-pats '^.{10,40}条款$'
```

伪表格过滤阈值（非空列占比 0.5 / 最长单元格 60 字 / 列数上限 12）一般无需改动。

表格还原流水线的判定依据、覆盖校验的正确姿势（禁止字符数对比）、页脚双格式、标题防误判规则等细节见 `references/notes.md`——在排查提取质量问题时加载该文件。

#### 已知限制

- 两栏版式（左窄栏标题 + 右宽栏正文）按位置排序拼接，个别换行处文字顺序可能有细微出入。
- 无框线表格与图片化内容检不出，保持纯文本流（内容不丢）。
- 合并单元格以空单元格表示（Markdown 无原生合并语法）。
- 提取结果可能含身份证号、账号等敏感信息，对外分享前提醒用户脱敏。

## 输出目录

- **主md文档**：
  - 文本层路线：与 PDF 同目录同名 `.md`（可用 `-o` 自定义），含 `<!-- 第 N 页 -->` 分页注释与还原表格

## 错误处理

**公共**：
- 用户指定的 PDF 不存在、不是 PDF、损坏或无法打开时，应当抛出错误并提示用户检查输入路径、文件格式。
- 缺少依赖（脚本会提示缺 PyMuPDF），按步骤1安装后重跑。

**文本层路线**：
- 检测退出码 1（无文本层/文本极少）时不要强行文本提取，应放弃文本提取，加载 pdf-img-to-md skill。
- 检测退出码 3（文本层乱码，乱码页占有效内容页 ≥5%）时**直接放弃文本层提取**，加载 pdf-img-to-md skill 走图片 OCR 路线；extract 脚本对乱码页占比 ≥5% 同样以退出码 3 中止且不产出文件，不要绕过守卫强行输出乱码内容。
- extract 脚本报告"校验回退页"属正常兜底（该页回退纯文本输出），交付时说明即可；报告"乱码回退页"时，这些页需按步骤3 导出 PNG 用多模态子agent识别后补齐。
